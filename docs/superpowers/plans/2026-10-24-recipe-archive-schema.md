## Archive schema contract

All hashes below are TEXT NOT NULL constrained to exactly64 lowercase hexadecimal characters. Ids/actors are nonempty TEXT; validate identity/type/bounds at future host entry points as well. SQL alone cannot authenticate a caller hash, grade or plaintext. Manifest/blob hashes must be equal. No cue, procedure, raw source or trace text goes in these tables.

- `improvement_recipes`: `id` primary key, `brain_id`, `experiment_id`, `context_id`, `target_id`, `base_revision_id`, `candidate_id`, nullable `comparison_report_id`, `manifest_hash`, `manifest_blob_hash`, `source_basis_hash`, `scope_hash`, `engine_config_hash`, `owner_rule_hash`, `source_authority_hash`, `target_protected_hash`, `language` vi|en, `verdict` helped|hurt|no_observed_effect|confounded|untested, `checked_at`, `expires_at`, `actor`, `created_at`. UNIQUE(id,brain_id), UNIQUE(brain_id,manifest_hash). FK all existing same-brain context/experiment/target/base/candidate/report records. INSERT guard joins the actual experiment/context/candidate/base target: candidate belongs to exact experiment/context/target/base; context scope/engine match; base revision belongs to target; target_protected_hash equals target.protected_hash at capture; owner_rule_hash is the separately host-authenticated protected-context rule aggregate, not the whole mutable target body. Optional report belongs to same experiment and comparison arm ordinal matches candidate. These are historical relational checks, not live destination permission. Require 0<=checked_at<=created_at<2**53 and created_at<expires_at<=created_at+2592000 (30day maximum, not a retention extension). Subsequent host capture must cap by actual shorter source freshness/retention; current EvidenceStore14day refs cannot silently become30day durable sources.
- `improvement_recipe_trial_refs`: `recipe_id`, `brain_id`, `position`0..3999, `trial_id`, `attempt`1|2, `result_id`, `result_hash`, `trace_hash`, `trace_count` positive integer. PK(recipe_id,brain_id,position), UNIQUE(recipe_id,brain_id,trial_id,attempt). FK recipe samebrain, actual trial samebrain and actual attempt, result id. INSERT guard authenticates result row's brain/trial/attempt/hash/blobhash, and the trial's existing experiment ownership (preparation link or comparison trial link) belongs to recipe.experiment_id/context. Rows may be inserted only before availability row is sealed; no late evidence additions. Trace hash/count are immutable reference pins, not SQL proof of trace integrity. Future host capture must reconstruct actual observations/result projection.
- `improvement_recipe_states`: `recipe_id` primary key, `brain_id`, `status` active|revoked|expired|superseded|erased, `generation` positive integer, nullable `reason`, nullable `successor_id`, `changed_at`. FK recipe/successor samebrain. INSERT must be active/gen1/reasonNULL/successorNULL/changed_at=recipe.created_at. Update fixes identity; generation increments exactly1, changed_at monotone finite<2**53. Allowed active->revoked|expired|superseded|erased, and revoked|expired|superseded->erased. Erased terminal, no reactivation/delete. Reasons: revoked=owner_revoked; expired=retention_expired and changed_at>=expires_at; superseded=superseded with distinct active successor of samebrain,target,scope,engine,language,owner_rule_hash; erased=source_erased|owner_erased. Other statuses have successorNULL. Historical record/references remain immutable. Future readers must check expires_at even before an explicit expiry transition, and erased remains unavailable regardless of ciphertext presence.

Add immutable UPDATE/DELETE triggers for recipes/trial_refs, a no-delete state trigger and exact state/insert/scope guards. Add catalogue index on recipes(brain_id,scope_hash,target_id,engine_config_hash,language,expires_at,id) and source lookup on trial_refs(brain_id,trial_id,attempt). No destination grant or inferred readiness column.
