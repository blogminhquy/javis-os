## vi
### Thêm mới
- **Hộp thư link không tốn token.** Thả link (Instagram, TikTok, ...) vào khung chat hoặc Telegram, server ghi thẳng vào bảng tham khảo mà không gọi AI. Kèm ghi chú ngắn vẫn được, có dấu hỏi hoặc câu phân tích thì chuyển sang AI như thường.

## en
### Added
- **Zero-token link hub.** Drop a URL (Instagram, TikTok, ...) into the dashboard chat or Telegram and the server appends it to the reference hub table without invoking any AI model. A short note is fine; a question mark or analysis keywords route the message to the AI as usual.
