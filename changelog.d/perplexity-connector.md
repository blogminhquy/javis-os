## vi
### Thêm mới
- **Có sẵn thẻ Perplexity trên trang Kết nối.** Dán API key của Perplexity là Javis tìm web có dẫn nguồn, hỏi đáp thông tin mới, suy luận nhiều bước và nghiên cứu sâu ra báo cáo, trên mọi bộ não.
- **Mặc định Chỉ đọc, bấm Kiểm tra không tốn credit.** Cả 4 công cụ chỉ đọc web. API Perplexity tính phí theo lượt dùng, hướng dẫn trên thẻ nói rõ công cụ nghiên cứu sâu là tốn nhất.

### Bảo mật
- **Lỡ dán key Perplexity (`pplx-...`) vào chat thì nhật ký tự che đi**, giống key OpenAI hay Tavily.

## en
### Added
- **A Perplexity card on the Connections page.** Paste a Perplexity API key and Javis can search the web with sources, answer on fresh information, reason in several steps and run deep research into a report, on every brain.
- **Read-only by default, and Check spends no credit.** All 4 tools only read the web. The Perplexity API is billed per use, and the card's guide says the deep research tool costs the most.

### Security
- **A Perplexity key (`pplx-...`) pasted into chat is masked in the logs**, like an OpenAI or Tavily key.
