## vi
### Thêm mới
- **Project tự học ngữ cảnh.** Trong lúc làm việc ở một project, Javis tự ghi lại điều bền và riêng của project đó (sự thật, quyết định đã chốt, thuật ngữ) và dùng lại ở mọi cuộc trò chuyện sau trong project, nên bạn không phải giải thích lại.
- **Thả tài liệu vào chat là đủ.** File hay link bạn đưa vào chat để dùng lâu dài được Javis tự gắn vào project kèm một dòng nói nó chứa gì. Nhờ dòng mô tả đó Javis biết mở đúng tài liệu mà không cần ghim cả file.
- **Tab "Đã học" trong khung project.** Xem, sửa, xoá, thêm ghi chú ngay ở đó. Ghi chú bạn viết hay sửa là của bạn và không bị thay khi đầy.
- **Ô Hướng dẫn vẫn là của bạn.** Javis chỉ sửa hướng dẫn riêng khi bạn bảo thẳng trong chat, và trả lại bản cũ để khôi phục.

## en
### Added
- **Projects learn their own context.** While working in a project, Javis notes what is durable and specific to it (facts, settled decisions, terms) and uses it in every later chat of that project, so you do not explain things again.
- **Dropping a document into the chat is enough.** A file or link you bring into the chat for long-term use is attached to the project by Javis, with one line saying what it holds. That line lets Javis open the right document without pinning the whole file.
- **A "Learned" tab in the project drawer.** Read, edit, delete and add notes there. A note you write or edit is yours and is not replaced when the list is full.
- **The Instructions box stays yours.** Javis rewrites a project's instructions only when you say so in chat, and hands back the old text so it can be restored.
