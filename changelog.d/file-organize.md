## vi
### Thêm mới
- **Tab Sắp xếp trên trang Dọn ổ đĩa**: chọn thư mục, chọn cách xếp (theo loại, loại rồi năm, loại rồi tháng, theo ngày), bấm Lập kế hoạch để xem trước từng thư mục đích, bỏ chọn chỗ không muốn rồi mới Thực hiện.
- **Nhờ Javis xếp theo chủ đề**: Javis đọc danh sách file và đề xuất thư mục như khách hàng, dự án, hoá đơn, hợp đồng; bạn duyệt trên trang trước khi chuyển.
- **An toàn và hoàn tác được**: ảnh xếp theo ngày chụp, thư mục dự án (có .git, package.json...) được giữ nguyên, không bao giờ ghi đè file trùng tên, mỗi lần sắp xếp đều hoàn tác được trong Lịch sử.

## en
### Added
- **Organize tab on the Disk cleanup page**: pick a folder and a way to sort (by type, type then year, type then month, by date), press Make a plan to preview every destination folder, untick what you do not want, then Carry out.
- **Ask Javis to sort by topic**: Javis reads the file list and proposes folders such as clients, projects, invoices, contracts; you review them on the page before anything moves.
- **Safe and undoable**: photos are filed by the date taken, project folders (with .git, package.json...) are left whole, same-name files are never overwritten, and every run can be undone from History.
