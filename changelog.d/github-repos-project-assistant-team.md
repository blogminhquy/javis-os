## vi
### Thêm mới
- **Gắn repo GitHub vào Project.** Mở khung project, tab Tài liệu, bấm Thêm tài liệu rồi chọn Repo GitHub. Mọi cuộc chat trong project tự có repo đó ngay từ tin đầu, mỗi cuộc làm trên một nhánh riêng.
- **Gắn repo vào tài liệu của Cộng sự.** Mỗi cuộc chat riêng với trợ lý đó cũng tự có repo, Javis vẫn tự commit, đẩy lên GitHub và mở PR như thường.
- **Chọn repo ngay lúc tạo Nhóm.** Trong mục tài liệu của hộp Tạo nhóm có nút Gắn repo GitHub, nhóm tạo xong là repo đã sẵn.

## en
### Added
- **Add GitHub repos to a Project.** Open the project panel, Documents tab, Add document, then GitHub repo. Every chat in the project gets the repo from its first message, each on its own branch.
- **Add repos to an Assistant's documents.** Every private chat with that assistant gets them too, and Javis still commits, pushes and opens the PR as usual.
- **Pick repos while creating a Team.** The documents part of the Create team box has an Attach a GitHub repo button, so the new team starts with its repos.
