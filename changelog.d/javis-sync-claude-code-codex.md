## vi
### Thêm mới
- **Hội thoại Claude Code và Codex tự lưu vào Javis.** Cài Javis Sync một lần trên máy (một lệnh `install`), mỗi lượt xong là câu anh gõ và câu trả lời cuối hiện trong Lịch sử dưới tên "Từ Claude Code: ..." hay "Từ Codex: ...", và vào vòng tự học.
- **Không tốn hạn mức, không lo mất.** Javis không chạy model cho việc này, API key được che trước khi lưu, Javis tắt thì lượt chờ gửi bù sau. Hướng dẫn ở trang Plugin, mục Javis Gate.

## en
### Added
- **Claude Code and Codex sessions are saved into Javis automatically.** Install Javis Sync once per machine (one `install` command) and each finished turn, your prompt and the agent's final answer, appears in History as "From Claude Code: ..." or "From Codex: ...", and feeds self-learning.
- **No quota spent, nothing lost.** Javis runs no model for it, API keys are masked before saving, and turns wait and resend when Javis is off. Setup is in the Plugins guide, Javis Gate section.
