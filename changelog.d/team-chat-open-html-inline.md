## vi

### Cải thiện

- File .html mà cộng sự gửi trong Team chat (thẻ file hoặc danh sách Tài liệu) giờ mở thành một tấm phủ ngay trong chat, dùng cùng trình xem an toàn như chat chính, kèm nút "Mở tab mới". Ctrl hoặc Cmd khi bấm vẫn mở tab mới.

## en

### Improved

- An .html file an assistant sends in Team chat (file chip or the Files list) now opens as a sheet over the chat, drawn by the same sandboxed preview as the main chat, with an Open in new tab button. Ctrl or Cmd click still opens a new tab.
